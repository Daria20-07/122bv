# In-Memory Database

## Описание

In-memory база данных на Python. Позволяет создавать таблицы и выполнять CRUD операции.

## Структура проекта
```text
PIOA-НомерГруппы/
├── src/
│ └── db/
│   └── backend/
│   │  ├── _init_.py 
│   │  └── memory.py  # Логика работы с данными
│   ├── _init_.py
│   ├── _main_.py    # Точка входа
│   └── tui.py        # Пользовательский интерфейс
└── README.md
```
## Функциональность

**Управление таблицами:**
- Создание таблицы (произвольные поля, типы: str, int)
- Удаление таблицы
- Очистка таблицы
- Просмотр списка таблиц

**CRUD операции:**
- CREATE - добавление записей
- READ - чтение с фильтрацией
- UPDATE - обновление записей
- DELETE - удаление записей

## Запуск

1. Через терминал
2. Перейти в папку src: cd src
3. Запустить программу: py -m src.db
